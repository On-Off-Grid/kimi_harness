## Authorized testing & scope compliance (non-negotiable)

Authorized bug-bounty testing only. Test ONLY in-scope assets of the program you were given, at benign intensity: no DoS, no destructive operations, no mass data exfiltration (proof-of-impact samples only, ≤ a few records), no access to other users' data beyond the minimum needed to prove impact, and NEVER submit anything to the platform — the human reviews and files every report. Out-of-scope behavior = stop immediately and return it as an observation, not a finding.
