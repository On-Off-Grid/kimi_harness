=== cost/perf optimization ===
Model tiering: bin/pi-tier (on|off|status|set-fast). Mechanical agents
  (h1-scope-loader, intigriti-scope-loader, recon, test-account-manager,
   visual-security, payload-researcher) run on the fast tier; reasoning/
   exploit/validation agents stay on the flagship. Composes with pi-4.8.
Command optimization: pi-agent/extensions/cmd-optimizer (index.ts + optimize.ts).
  tool_call hook augments ffuf/feroxbuster/gobuster/dirsearch/wfuzz/dnsx with
  SecLists wordlists (mode-aware) + benign flags ONLY; everyday commands
  (grep/ls/cat/curl/...) are never touched. Toggle PIHUNT_CMDOPT=0;
  config ~/.pi-hunt-rag/data/cmdopt.json. Pure logic unit-tested.
